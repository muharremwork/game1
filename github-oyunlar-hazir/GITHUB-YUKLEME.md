# GitHub’a yükleme

1. `GitHub-Oyunlar-Hazir.zip` dosyasını bilgisayarında çıkart.
2. GitHub’da bir depo aç. Yeni depo oluşturacaksan adını `oyunlar` yapabilirsin.
3. Depodaki dosya yükleme seçeneğini aç: **Add file → Upload files**.
   Boş depoda **uploading an existing file** bağlantısı da görünür.
4. Çıkarttığın klasörün içindeki `sur-kusatmasi` klasörünü ve yanındaki
   `README.md`, `GITHUB-YUKLEME.md`, `.gitignore` dosyalarını yükleme alanına sürükle.
5. Yüklenecek dosyaları kontrol et ve **Commit changes / Propose changes** ile kaydet.

ZIP’i tek dosya olarak yüklemek yerine içindeki klasör ve dosyaları yükle.
`sur-kusatmasi` klasör yapısını koru; böylece oyun dosyaları GitHub’da tek tek görünür.

## PC’de oyunu başlat

Paketi çıkarttıktan sonra `sur-kusatmasi/OYUNU-BASLAT.html` dosyasına çift tıkla.
Doğrudan giriş dosyası: `sur-kusatmasi/pc/dist/index.html`.

## Android

Kurulum dosyası: `sur-kusatmasi/android/Sur-Kusatmasi-Android.apk`.
Android kopyası ayrıdır; son PC güncellemeleri bu eski APK’ya otomatik aktarılmaz.

Bu paket GitHub’a dosya yüklemek içindir. GitHub’a yüklemek oyunu kendiliğinden
oynanabilir bir internet sitesine dönüştürmez; bunun için ayrıca barındırma gerekir.

Resmî yükleme kılavuzu: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
