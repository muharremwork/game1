# Poison, artillery and fortress cards

Six offensive card types now deal three unique random cards to each side. New poison
buff lasts 12 seconds; ranged troops and ranged weapons inflict six seconds of poison,
eight HP per second. It refreshes without stacking, ticks while frozen and stops when
paused. It does not affect bases or melee attacks. Poison ticks ignore armor.

Heavy splash buff lasts 12 seconds. Eligible unmounted cannons/catapults are the
original heavy siege slot, mortar/heavy catapult, or equipment with at least 150 base
damage. Radius is 110 world units using 2D distance, including adjacent corridors.
Normal splash remains restricted to its lane. Enhanced base hits also splash nearby
defenders, using the attack's base damage; base HP is deducted only once.

Every side always receives three dedicated fortress cards in the Kale tab; none uses
supply. All last five seconds. Shield blocks 100% of incoming attack damage (35s
cooldown). Reflection returns the actual base damage to the exact attacker, ignoring
its armor (40s cooldown). The base still takes this damage; reflection cannot recurse.
When shield blocks a hit, there is no damage to reflect. Spikes deal 40 damage/sec in
all five lanes within x≤390 for the left base or x≥1050 for the right base (38s cooldown).
Spike damage respects troop armor. Allies are unaffected. Partial expiry ticks count
only the remaining duration, and dead units enter the ordinary kill accounting.

Solo enemy AI activates fortress defenses under nearby threats. Two-player hands,
cooldowns and effects remain independent. UI tabs retain the compact three-card row.
PC/web update is separate from the Android application.
